01

Seven load locations

Project root CLAUDE.md or .claude/CLAUDE.md; project rules and parent rules; parent CLAUDE.md; child CLAUDE.md on demand; local CLAUDE.local.md; private user CLAUDE.md; and user rules. This lab creates all seven categories, not every alternative file spelling.

02

Additive instructions

All selected layers can appear together. Avoid conflicts or state intended precedence explicitly in your own project text. This lab uses independent marker lines rather than conflicting language or package-manager rules.

03

Compaction and limits

Project-root CLAUDE.md is re-read after compaction. Nested instruction files and path-scoped rules must load again on demand. The live exercise observes a real boundary and subsequent compliance, not the full provider request payload. Keep files lean; caching and perfect model compliance are not guaranteed.

04

What belongs in CLAUDE.md

Repository conventions, architecture, build/test commands, lasting constraints and focused summary guidance. Write task-specific requests in user input and application-specific persona instructions in systemPrompt.

05

Configuration boundaries

The app uses private config/home paths, disables auto memory and connector discovery, and configures strict MCP. settingSources is not an OS sandbox and does not remove managed policy. Local personal notes should remain uncommitted.
