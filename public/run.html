04

Combine additive locations

Run User + project with a custom prompt. Then run omitted defaults and compare the local marker as well. These non-conflicting fixtures do not prove a universal precedence order.

npm run sample:env -- combined --custom
05

Test disabled and child instructions

Run the disable flag case. Then read feature/data.md in the child experiment and compare the observed child rule marker.

npm run sample:env -- disabled
npm run sample:env -- child
06

Observe compaction in the same session

Run Summary → compact → recall. Wait for the entire three-phase experiment. Verify an actual boundary and matching session IDs, then inspect the final returned markers.

npm run sample:env -- compact
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3115
# Windows if required: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

The npm scripts load the optional .env explicitly. Existing shell variables take precedence. Restart after edits. No Managed Agents agent or environment ID is needed.

Troubleshooting

If this app is already listening, startup prints its URL. If another service occupies the port, change PORT or stop that service. On Windows set CLAUDE_CODE_GIT_BASH_PATH to the installed bash.exe if necessary. Keep optional npm dependencies enabled. Check key/model access if a real query fails; errors are never replaced by a saved answer.
