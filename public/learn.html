Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Write lasting project knowledge

Use CLAUDE.md for conventions, architecture, build/test commands and compact summary guidance. Keep one-off task instructions in the task prompt.

02

Load the right source

project loads project/parent CLAUDE.md and rules; user loads personal instructions and rules; local loads CLAUDE.local.md. Omission and an explicit empty list are distinct.

03

Combine non-conflicting layers

Loaded instruction layers are additive. This lab uses different marker lines so students can observe compliance without inventing a universal precedence ladder.

04

Discover child instructions on demand

The child experiment reads feature/data.md while the working directory remains the project root. Observe whether the child CLAUDE.md instruction appears after that Read.

05

Observe real compaction

The compaction mode creates one owned persisted session, sends /compact, observes compact_boundary, then resumes the same session and checks the actual answer. Continued compliance is not a wire-level proof of reinjection.

06

Separate instructions from permissions

CLAUDE.md works with custom and preset system prompts as conversation context. A host Read guard independently limits tools to classroom data files. Markers describe model compliance, not a complete instruction audit.
